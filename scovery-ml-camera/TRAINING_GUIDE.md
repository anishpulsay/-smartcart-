# Custom Object Detection Training Guide

This guide will walk you through how to turn your downloaded internet images into a working, Raspberry P-ready YOLOv8 AI model for your Scovery Smart Cart.

## Step 1: Data Annotation
Downloading the images isn't enough; the AI needs to know *where* the items are in the pictures. We recommend using **Roboflow** for this.

1. Go to [Roboflow](https://roboflow.com/) and create a free account.
2. Create a new "Object Detection" project.
3. Upload the `training_dataset` folder (generated by our `scrape_images.py` script).
4. Go through each image and click-drag a **Bounding Box** over the product. 
5. Select "Generate Version".
6. Select "Export Dataset" -> Format: **YOLOv8** -> Download the exported `.zip` and extract it to a folder.

## Step 2: Training the AI
Once you have your Roboflow dataset folder, we use the `ultralytics` package to train the network on your custom data.

1. First, install the training library if you haven't:
   ```bash
   pip install ultralytics
   ```
2. Create a python script `train_custom_model.py`:
   ```python
   from ultralytics import YOLO

   # Load a pretrained lightweight model 
   model = YOLO('yolov8n.pt')

   # Train the model using the path to your extracted Roboflow data.yaml file
   results = model.train(data='path/to/roboflow/data.yaml', epochs=50, imgsz=416)
   ```
3. Run the script! It may take an hour or so depending on your computer, but once complete, your custom weights will be output as **`best.pt`** in the `runs/detect/train/weights/` folder.

## Step 3: Run Live Inference
Once you have `best.pt`, place it into your `scovery-ml-camera/models/` folder. 
I will update `main.py` to strip out MobileNet SSD and replace it with `model = YOLO("models/best.pt")` so you can use the custom AI directly with the webcam!
